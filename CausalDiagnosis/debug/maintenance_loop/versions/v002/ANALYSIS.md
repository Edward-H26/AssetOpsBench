## 解释与局限

先读取的prompt有效，但未解决连续空读、重复写操作或错误诊断。原工具契约在无MCP时限制task工具，缺少wait；该组仍能利用前向读取推进，MCP组需要使用实际可用的等待路径。两组可用工具不同，比较存在混杂。
